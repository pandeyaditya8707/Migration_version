Agentic Data Migration Planner and Reconciliation Workbench
Experience level: Expert
Expected focused effort: 7–10 hours

Build an application that helps plan and validate the migration of one bounded dataset from a source schema to a target schema.

Provided inputs:
* Source schema
* Target schema
* Sample source records
* Supported transformation rules
* A mock target database or staging store

AI agent:
* Propose field mappings
* Identify incompatible or missing fields
* Suggest supported transformations
* Explain mapping risks
* Generate clarification questions
* Prepare a proposed migration plan
* Use only the provided inspection and validation tools

The user must approve the mapping and transformation plan before execution.

Application requirements:
* Version migration plans
* Perform a deterministic dry run
* Quarantine invalid records
* Show source, transformed, accepted, and rejected counts
* Preserve field-level error evidence
* Execute an approved migration into the mock target
* Prevent duplicate insertion when a migration is retried
* Compare source and target totals
* Support rollback of the mock migration
* Preserve execution, approval, retry, and rollback history

Scope & Constraints:
* Limit the assignment to one source, one target, and a documented maximum sample size.
* Not required: production database access, arbitrary transformation code, distributed migration, or live cloud connectors.
